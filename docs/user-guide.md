
# GUIDE UTILISATEUR
## Application web de gestion d'un cabinet comptable

## 1. Présentation

Ce guide présente les principales fonctionnalités de l'application de gestion d'un cabinet comptable.

Il explique comment accéder à la plateforme et utiliser les différents modules selon le profil de l'utilisateur.

L'application comporte quatre profils principaux :
- Administrateur.
- Expert-comptable.
- Comptable.
- Client.

Chaque profil dispose de permissions correspondant à ses responsabilités.

## 2. Accès à l'application

Pour accéder à la plateforme :

1. Démarrer WampServer.
2. Ouvrir un navigateur web.
3. Saisir l'adresse de l'application.
4. Attendre l'affichage de la page de connexion.

L'utilisateur doit disposer d'un compte actif pour accéder aux fonctionnalités protégées.

## 3. Connexion

Sur la page de connexion :

1. Saisir son adresse électronique.
2. Saisir son mot de passe.
3. Cliquer sur le bouton de connexion.

Après vérification des informations, l'application redirige l'utilisateur vers son espace de travail.

En cas d'informations incorrectes, un message d'erreur est affiché.

## 4. Utilisation de l'espace administrateur

L'administrateur possède les responsabilités de gestion générale.

### 4.1 Tableau de bord

Le tableau de bord permet de consulter les informations générales de la plateforme.

Il peut notamment présenter :
- Le nombre d'utilisateurs.
- Le nombre d'entreprises.
- Les activités récentes.
- Les statistiques générales.

### 4.2 Gestion des utilisateurs

L'administrateur peut :
- Consulter les utilisateurs.
- Créer de nouveaux comptes.
- Modifier les informations.
- Activer ou désactiver les comptes.
- Attribuer les rôles.

### 4.3 Supervision

L'administrateur peut consulter les informations de suivi et les journaux d'audit afin de contrôler les activités importantes.

## 5. Utilisation de l'espace expert-comptable

L'expert-comptable intervient dans le contrôle et la supervision des opérations.

Il peut notamment :
- Consulter les entreprises accessibles.
- Examiner les écritures comptables.
- Contrôler les opérations.
- Valider les écritures selon ses permissions.
- Consulter les balances.
- Produire les états financiers.
- Suivre les informations fiscales.

## 6. Utilisation de l'espace comptable

Le comptable réalise les opérations quotidiennes.

### 6.1 Gestion des entreprises

Pour gérer une entreprise :

1. Ouvrir le module Entreprises.
2. Consulter la liste disponible.
3. Sélectionner une entreprise.
4. Créer ou modifier une fiche selon les permissions.

### 6.2 Gestion des exercices

Pour créer un exercice :

1. Accéder au module Exercices.
2. Cliquer sur le bouton de création.
3. Saisir le libellé.
4. Définir la date de début.
5. Définir la date de fin.
6. Enregistrer.

### 6.3 Gestion des comptes

Le module Comptes permet de consulter le plan comptable et d'enregistrer les comptes nécessaires selon les autorisations.

### 6.4 Gestion des journaux

Les journaux permettent de classer les opérations comptables.

Le comptable peut consulter les journaux disponibles et utiliser celui qui correspond à la nature de l'opération.

### 6.5 Saisie d'une écriture comptable

Pour enregistrer une écriture :

1. Accéder au module Écritures comptables.
2. Cliquer sur Nouvelle écriture.
3. Choisir l'entreprise.
4. Sélectionner l'exercice comptable.
5. Choisir le journal.
6. Saisir la date et le libellé.
7. Ajouter les lignes comptables.
8. Sélectionner les comptes concernés.
9. Renseigner les montants au débit et au crédit.
10. Vérifier l'équilibre de l'écriture.
11. Enregistrer l'opération.

Une écriture équilibrée respecte le principe suivant :

**Total Débit = Total Crédit**

### 6.6 Consultation du grand livre

Le grand livre permet de consulter les mouvements enregistrés pour chaque compte.

L'utilisateur peut rechercher les informations disponibles selon les critères proposés par l'application.

### 6.7 Consultation de la balance

La balance présente les soldes et les mouvements des différents comptes.

Elle facilite le contrôle de la situation comptable.

## 7. Utilisation de l'espace client

Le client dispose d'un accès limité aux informations de son entreprise.

Selon les permissions accordées, il peut :
- Consulter les informations de son entreprise.
- Consulter les documents disponibles.
- Consulter les factures.
- Suivre les notifications.
- Accéder aux informations financières autorisées.

## 8. Gestion fiscale

Le module Fiscalité permet de consulter les informations relatives aux taxes, à la TVA et aux déclarations.

Les utilisateurs autorisés peuvent :
- Consulter les informations fiscales.
- Examiner les données relatives à la TVA.
- Suivre les déclarations.
- Consulter les échéances fiscales.

## 9. Consultation des états financiers

L'application prévoit plusieurs documents financiers :

- Le bilan.
- Le compte de résultat.
- La balance générale.
- Le grand livre.

Ces documents permettent d'analyser les informations comptables d'une entreprise.

## 10. Gestion des factures et documents

Le module Factures permet de consulter les factures disponibles.

Le module Documents permet de retrouver les pièces justificatives et les fichiers associés aux dossiers.

L'utilisateur doit respecter les autorisations d'accès lors de la consultation ou de la manipulation des documents.

## 11. Notifications

Les notifications permettent d'informer les utilisateurs des événements importants.

L'utilisateur peut consulter les notifications disponibles et suivre leur état de lecture lorsque cette fonctionnalité est activée.

## 12. Déconnexion

Pour quitter l'application :

1. Cliquer sur le menu du profil.
2. Sélectionner Déconnexion.
3. Attendre le retour à la page de connexion.

Il est recommandé de toujours fermer sa session après utilisation, particulièrement sur un ordinateur partagé.

## 13. Bonnes pratiques

Pour une utilisation correcte de la plateforme :

- Vérifier les informations avant leur enregistrement.
- Utiliser le bon exercice comptable.
- Sélectionner le journal approprié.
- Vérifier l'équilibre des écritures.
- Protéger ses identifiants.
- Ne pas partager son compte.
- Respecter les permissions accordées.
- Signaler les anomalies à l'administrateur.

## 14. Conclusion

Ce guide facilite la prise en main de l'application par les différents utilisateurs.

Il présente les principales opérations nécessaires à la gestion administrative, comptable et fiscale d'un cabinet comptable.
